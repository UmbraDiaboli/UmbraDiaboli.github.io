Beginnings

Posted Sep 30, 2026
By Umbra Diaboli
1 min read

He hit the enter key with a final triumphant stroke. It couldn’t have been that easy, they hadn’t patched their web application firewalls. There was a new exploit available. The api exposed an insecure stored procedure in the embedded sql database allowing full admin access to the hardware meant to keep all of their internal systems safe. He took a swig of vodka and racked another line of cocaine, his mind electric. “Lets see what secrets you have to show me.” He said to the room in general. The firewalls ran a unix OS, with a full enough set of tools to set up camp and poke around. A bash shell and telnet was enough for now. To be on the safe side he echoed out a little script in the init.d directory so even if they discovered him his legacy would live on in infamy. This was a fortune 500, the big leagues, the ultimate puzzle to solve and nut to crack. He began sniffing around. He could see DMZ web servers, at least they went to the trouble of segmenting their network. He hopped from the web application firewall to a server that was running an old open source web server using path traversal, now it was time to have some real fun and take this girls underwear off. Another line, the vodka was having no effect but his hands were shaking. Finn was getting close, he’d been poking around their security for the last week seeing what they were running and how it worked. He dumped out the logins on the web server. There was only one that looked interesting. The account of a dipshit system admin he would bet was also running domain admin. Because of course he was, they all did. Finn copied the password hashes back over his terminal to crack later and echoed out the same init.d party popper, with an ascii middle finger for whoever found it. “,,!,, -.- ,,!,,. Courtesy of the shadow demon.”
